-/-INSTALACIÓN DE VISUAL STUDIO CODE (VSC):
Para cualquier tipo de descarga e instalación de programas hay que tener en cuanta el tipo de sistema que se tiene en el computador, normalmente están basados en x64. Se puede encontrar el tipo de sistema escribiendo "información de sistema" en la barra de tareas.
Para instalar VSC hay que dirigirse a la pagina official de este programa: https://code.visualstudio.com/ y descargar el archivo VSCodeUserSetup, correrlo y seleccionar las opciones que normalmente se aplican para cualquier otro programa al instalarlo.
En el caso de querer usar VSC con un lenguaje de programacion i.e. Python, solo se tiene que ir a la barra de la izquierda y precionar el ícono llamado "Extensions", seleccionar "Python" o cualquier lenguaje deseado y para este caso tambien instalar la extención llamada "Code Runner" para más conveniencia.

-/-CREAR UNA CUENTA DE GITHUB Y CREAR UN REPOSITORY:
Una recomendación es vincular VSC con un perfil personal de GitHub, para esto primero hay que crear una cuenta es la pagina oficial: https://github.com/ usando un email personal, un nombre de usuario y una contraseña.
En VSC, seleccionar el icono de configuración en la parte inferior izquierda, seleccionar "settings", Click en el botón azul de "Backup and sync settings", después en el botón azul de "sign in" y seleccionar "Sign in with GitHub", al hacer el inicio de sesión, seleccionar el botón verde "Authorize VSC". -/-Esto conectará VSC CON GitHub-/-.
Al obtener el perfil de GitHub tenemos que crear un "Repository", para esto hay que dar click en la imagen que está en la parte superior derecha y seleccionar "Repositories" seguido del botón verde de "new".
En esta nueva página se le dará un nombre al Repository, dejando de lado la descripción, y en la sección de configuraciones en el apartado de "Choose visibility" seleccionar "Public" en el caso de no estarlo; en "Add README" cambiar el botón a "on"; en "Add .gitignore" dejarlo como "No .gitignore" ya que por el momento no será necerario usar esta herramienta y finalmente en "Add license" seleccionar "GNU General Public License v3.0". Después de completar con lo ya dicho dar click al botón verde de "Create repository". Seleccione la carpeta en su computador que prefiera para guardar el repositorio.

-/-INSTALACIÓN DE GIT-/-
Ahora en VSC en la barra izquierda seleccionamos el icono de "Source control", presiona el botón azul de "Download Git for Windows", el cual nos llevará a la pagina de Git.
Es necesario instalar Git, solo se tiene que descargar el archivo de la pagina oficial: https://git-scm.com/ en la sección de Instalador Independiente para mayor facilidad. Al hacer la instalación dar click en "next" hasta llegar a la pregunta: "Choosing the default editor used by Git", seleccionar "use VSC as Git's default editor" y dar click en "next" hasta que inicie la instalación.

-/-CLONAR UN REPOSITORIO DE GITHUB EN VSC-/-
Presione Ctrl + Shift + P para abrir el "Command Palette" o seleccione la primera opción en el icono de configuraciones, escriba "Git Clone" y seleccione "Clone from GitHub" para que aparezca el link de su repositorio en GitHub. Después de esto se debería de abrir la ventanilla de documentos en el cual debe buscar la carpeta asignada con el nombre que le dió a su repositorio. VSC le dará la opción de abrir este documento en un Workspace que ya se esté trabajando o una ventana nueva seguido de su seleccion VSC preguntará si confia en el autor del repositorio.
En la barra izquierda de "Explorer" bajo el nombre de su repositorio deberían estar la Licencia y el README.md creados. Precione el icono de carpeta nueva y nombre dicha carpeta, después precione el icono de archivo nuevo para nombrarlo a su gusto o como se le asigne por su profesor. Ya puede hacer cualquier tipo de cambio en su repositorio.

-/-INSTALACIÓN DE VIRTUAL BOX (VB) Y UBUNTU-/-
Entre a la pagina oficial en: https://www.virtualbox.org/ y descargue el Setup de su preferencia. Al iniciar la instalación es posible que VB mencione que necesita "Microsoft Visual C++ 2019 Redistributable Package", para esto tiene que dirigirse a la pagina de Microsoft: https://learn.microsoft.com/es-es/cpp/windows/latest-supported-vc-redist?view=msvc-170 y en la parte de "Versión redistribuible compatible más reciente" descargar el documento que requiera. Al instalarlo es probable que necesite reiniciar la computadora para que Windows registre los nuevos componentes de forma apropiada.
En la pagina oficial de Ubuntu: https://releases.ubuntu.com/ puede escoger la version de Desktop Image que más le plazca para usar en la VB (el proceso de descarga puede tardar varios minutos dependiendo de la estabilidad de conexión).
Al terminar la instalación y abrir VB haga click en "Nueva", en la ventana que abre escriba un nombre para su Virtual Machine, es recomendable que la carpeda de su VM la deje tal cmo aparece, en "ISO image" busque y seleccione la imagen de Ubuntu que descargó para al final presionar "Siguiente".
En la nueva ventana escriba el nombre de usuario y cree una contraseña; el nombre del dominio debe dejarse tal y como aparece. Presione Siguiente y en la barra de "Base Memory" se recomienda usar entre 4 y 8GB de RAM (1/3 de los recursos de la PC) o un poco más de la mitad de la barra verde dependiendo del estado de su computador, en "Number of CPUs" deslice a 2CPU y para el tamaño del disco duro por default esta en 25GB que es lo recomendado para Ubuntu como minimo.
La casilla de "Use EFI" es un soporte experimental para el Extensible Firmware Interface (EFI), que es un estándar industrial destinado para reemplazar la BIOS heredada como interfaz principal para arrancar ordenadores y ciertos servicios del sistema más adelante, dicha casilla no es necesaria para la instalación.
Precione Terminar al aparecer la ventana de Resumen para que arranque la VM, esto puede tardar varios minutos por lo que es recomendado conectar su LapTop de ser la herramienta con la que se está realizando este proceso.
Al finalizar seleccione su usuario y escriba su contraseña creada para acceder a la maquina virtual. Finalmente, Ubuntu le pedirá completar unos pasos para acceder al escrotorio.
Actualice Ubuntu presionando el botón del logotipo de Ubuntu, "settings", en las opiciones del lado izquierdo baje hasta encontrar "system" y seleccione "software updates" para realiazar la actualización. La VM le pedirá reiniciar para instalar correctamente las actualizaciones.
Para guardar la sesión de la VM precione la "x" de la parte superior derecha para cerrarla y en la ventanilla que aparece seleccione "Guardar el estado de la maquina" y Aceptar.

-/-GUARDAR CAMBIOS EN VSC Y SINCRONOZARLOS EN GITHUB-/-
Primero debemos de abrir la terminal. Para esto en el menú superior podemos ver "terminal", aqui presionamos "new terminal" y escribimos los siguientes comandos:
git config --global user.name "NOMBRE_APELLIDO"
git config --global user.email "MiNombre@ejemplo.com"
De no hacer esto no se podran guardar los cambios ni la sincronización ya que aparece un error por falta de información.
Al hacer un cambio, VSC notificá al usuario en el icono de "Source Control" por lo cual se tiene que guardar esos cambios, para esto presione el signo de "+" a lado de "changes", agregue un nombre designado por el profesor para estos cambios y haga click en "Commit". Los cambios serán reflejados en su perfil de GitHub al presionar "sync".
Para cualquier cambio o actualización adicional presione ctrl + S para que "Source Control" notifique de sus cambios, nombre su actualización, precione "Commit" y "sync".

-/-CREACIÓN DE CARPETAS Y DOCUMENTOS EN UBUNTU USANDO LA TERMINAL-/-
Para abrir la terminal precione el icono del menu principal en la parte inferior izquierda y seleccione la terminal.

El comando "ls" en la raiz del kernel "NOMBRE DE USUARIO@NOMBRE DE VM" enlista las carpetas dentro de ella.

Al estar en esta ventanilla hay que ingresar los siguientes comandos:
mkdir -p ~/laboratorio-cli/{docs,src,logs}
Este crea las carpetas de "docs, src y logs".

**En el caso de algun error al escribir el nombre de una carpeta o alchivo, para borrar un elemento el comando es "rm " seguido del nombre de la carpeta y/o "rm -r " seguido de archivo.**

cd ~/laboratorio-cli
Este comando nos lleva a la carpeta de "laboratorio-cli"
el comando "ls" dentro de la carpeta "laboratorio-cli" enlista las carpetas dentro de ella.

touch docs/{guia,notes}.md src/{main,test}.py logs/app.log README.txt
Este comando crea documentos dentro de las carpetas creadas anteriormente y al aplicar "ls" reveralá las carpetas de docs, logs y src pero ahora con el documento de README.txt.

El comando "cd ./docs" es para retroceder una carpeta. Usando dos puntos "cd ../docs" salta dos carpetas.
También podemos usar el comando "cd ~/laboratorio-cli/docs" por ejemplo, para dirijirnos a una carpeta en especifico.

Al ubicarnos en la carpeta de docs, src o logs y escribir el comando "ls" nos dira el contenido de las mismas.

printf 'error\nok\nerror\n' > logs/app.log
Este comando escribe "error ok error dentro del documento "app.log" dentro de la carpeta "logs". La "n" es un salto de letra.

nano logs/app.log
Abrirá un "bloc de notas" con una interfaz muy básica que solo se puede usar usando el teclado. Por ejemplo, para guardar algo escrito dentro de el presionamos "ctrl+S" y para salid de él presionamos "ctrl+x".

-/-MÁS COMANDOS DE UBUNTU-/-

ls -lah docs
Este comando revela el valor de permisos en las archivos dentro de "docs".

Ejemplo:
drwxrwxr-x
-1er grupo de 3 = Administrador
-2do grupo de 3 = Grupos de Usuarios
-3er grupo de 3 = Otros

Valores:
Ignorar "d" / r=4 / w=2 / x=1 / -=0
rwx=7 / rwx=7 / r-x=5
=775

DNS de preferencia = valor de 604

Si el 3er grupo tiene un valor alto se puede aplicar "chmod" que puede cambiar los valores de permisos a 007 dando total control

El comando "pwd" te lleva a la raiz de los documentos.

ls -lah
Enlista el valor de permisos dentro del kernel.

cd docs && pwd
los signos "&&" (and) conbinan comandos.

"cd -" te lleva a la carpeta usada anteriormente y al aplicarla nuevamente regresa al frente creando un ciclo entre dos carpetas al aplicarla varias veces.

"cd /" lleva la raiz del kernel y con "ls" muestra las carpetas dentro en él.

"cd ~" + "ls" te lleva a las carpetas root de usuario.

"realpath ." y "pwd" tienen la misma función.

type cd
Este comando tendrá el texto: "cd is shell builtin" para llegar aqui es probable tener que usar los comandos: "cd ~" y "cd laboratorio-cli/src && pwd" de lo contrario se mostrará el texto: "bash: cd: ../src: No such file or or directory"

help cd
Muestra la lista de comandos y sus funciones de cforma compacta

ls --help
Tiene las misma función pero la información de los comando es más extensa.

man ls
Abre otra ventana con la lista de comandos de usuario.

info coreutils
Abre el manual de las utilidades principales del GNU, incluyendo los programas estandard para la manipulación detextos y archivos.

apropos 'list directory'
Revela una lista de comandos relacionados con la acción de listar el contenido de un directorio. Esto incluye comandos como "ls" y "dir".
